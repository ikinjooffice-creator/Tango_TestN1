Target 1900 Listening Cards

使い方
1. iPhoneで index.html をSafariで開きます。
2. 「学習条件」でPart / Section / No.範囲を選び、「学習開始」を押します。
3. 最初のボタン操作後は、単語表示と同時に英語音声が自動再生されます。
4. 指定秒数後に意味と例文が同時表示され、その後、指定秒数で次の単語へ移ります。
5. 「停止」「前へ」「次へ」「もう一度読む」「意味を表示」が使えます。
6. 各単語は「◎ 即答」と「連続正解 0〜3回」を手動で記録できます。
7. 学習データはiPhoneのブラウザ内に保存されます。必要に応じて「学習データを書き出し」でバックアップしてください。

注意
- 添付PDFには例文が含まれていなかったため、初期例文は編集前提の簡易文です。
- 例文欄は各単語ごとに編集・保存できます。
- Safariの履歴やサイトデータを削除すると学習記録が消える場合があります。
