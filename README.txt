Target 1900 Listening Cards v2

使い方
1. index.html をiPhoneのブラウザで開きます。
2. ⚙から学習条件を設定します。
3. 学習開始を押すと、単語表示と同時に英語音声が自動再生されます。
4. 指定秒数後、あらかじめ確保された空欄に意味・例文・訳が表示されます。
5. Ⅱで停止、▶で再開、◀/▶で前後移動、↻でもう一度読み上げ、⌄で手動表示できます。
6. カード右上の◎で即答ON/OFF、①/②/③で回数を切り替えます。

変更点
- 意味・例文の表示領域を最初から固定し、表示時のUIの移動を抑えました。
- 操作ボタンをできるだけ記号化しました。
- 即答と回数をカード右上の小さなボタンにしました。
- 回数は0を廃止し、1→2→3→1で切り替えます。
- 例文を「単語がこの文に出てくる」形式から、短い英文例文に差し替えました。

注意
- 音声は端末・ブラウザ内蔵の読み上げ機能を使います。
- 学習記録はブラウザ内に保存されます。Safariのサイトデータを消すと消える場合があります。

v20: 苦手フラグ、苦手モード、苦手CSV書き出しを追加。苦手フラグは学習データ復元JSONとは別にブラウザ内へ保存されます。
